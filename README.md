# riri-playground · 총무 오피스 🏢

파스텔 3D 사무실에서 팀원들의 상태(업무중 · 탕비실 · 카페 · 화장실 · 옥상 · 월루중 · 연차)를 실시간으로 함께 보는 페이지예요.

- 캐릭터를 골라 "내 캐릭터"로 정하고 상태를 바꾸면 그 구역으로 걸어가요.
- 고양이 6마리: 쓰다듬기 / 츄르 / 놀아주기.
- 옥상에서는 담타 / 소리지르기.

## Firebase 연결하기 (처음 한 번)

1. [Firebase 콘솔](https://console.firebase.google.com)에서 프로젝트 만들기.
2. **빌드 → Authentication → 시작하기 → 로그인 방법 → 익명** 사용 설정.
3. **빌드 → Firestore Database → 데이터베이스 만들기** (위치 `asia-northeast3 (서울)`, 프로덕션 모드).
4. Firestore **규칙** 탭에 이 저장소의 `firestore.rules` 내용을 붙여넣고 게시.
5. **프로젝트 설정 → 내 앱 → 웹 앱 추가(</>)** 후 나오는 `firebaseConfig` 값을 `firebase-config.js`에 붙여넣기.
6. **Authentication → 설정 → 승인된 도메인**에 `bborami.github.io` 추가.

## 리리(주인) 로그인

1. Authentication → 로그인 방법 → **이메일/비밀번호** 사용 설정.
2. Authentication → 사용자 → 사용자 추가: 이메일 `riri@riri-playground.app`, 비밀번호는 직접 정하기.
3. Authentication → 설정 → 사용자 작업 → **생성(가입) 사용 설정 해제** (다른 사람이 계정을 못 만들게).
4. 페이지 오른쪽 아래 **👑 리리 로그인** → 비밀번호 입력. 어느 기기에서든 리리가 돼요.

- **리리가 먼저 로그인해야** 사무실이 열려요 (처음 로그인할 때 리리 캐릭터가 만들어져요).
- 다른 사람들은 **➕ 내 캐릭터 만들기**를 누르면 랜덤 캐릭터가 하나 생겨요 (최대 40명 + 리리).
- 내 캐릭터는 ✏️로 이름 변경, 🗑로 지우기. 리리는 아무 캐릭터나 내보낼 수 있어요.
- 익명 로그인이라 브라우저마다 다른 사람으로 취급돼요.

## 무료 사용량 (Spark: 하루 읽기 5만 / 쓰기 2만)

- 상태를 한 번 바꾸면 보고 있는 사람 수만큼 읽기가 생겨요.
- 탭을 3분 넘게 안 보면 실시간 구독을 끊었다가 다시 보면 연결해요.
- 접속자 수는 5분마다 한 번만 세요.
- 넘으면 그날 오후 5시(한국 시간)까지 멈춰요. 걱정되면 Blaze(종량제)로 바꾸세요.

`firebase-config.js`가 비어 있으면 서버 없이 혼자 보기 모드로 열려요.
