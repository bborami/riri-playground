# riri-playground · 총무 오피스 🏢

파스텔 3D 사무실에서 팀원들의 상태(업무중 · 탕비실 · 카페 · 화장실 · 옥상 · 월루중 · 연차)를 실시간으로 함께 보는 페이지예요.

- 캐릭터를 골라 "내 캐릭터"로 정하고 상태를 바꾸면 그 구역으로 걸어가요.
- 고양이 6마리: 쓰다듬기 / 츄르 / 놀아주기.
- 옥상에서는 담타 / 소리지르기.

## Firebase 연결하기 (처음 한 번)

1. [Firebase 콘솔](https://console.firebase.google.com)에서 프로젝트 만들기.
2. **빌드 → Authentication → 시작하기 → 로그인 방법 → 익명** 사용 설정.
3. **빌드 → Firestore Database → 데이터베이스 만들기** (위치 `asia-northeast3 (서울)`, 프로덕션 모드).
4. Firestore **규칙** 탭에 이 저장소의 `firestore.rules` 내용을 붙여넣고 게시.
5. **프로젝트 설정 → 내 앱 → 웹 앱 추가(</>)** 후 나오는 `firebaseConfig` 값을 `firebase-config.js`에 붙여넣기.
6. **Authentication → 설정 → 승인된 도메인**에 `bborami.github.io` 추가.

## 처음 열 때

- **주인(리리)이 가장 먼저 열어야 해요.** 처음 연 브라우저가 주인이 되고, 리리와 캐릭터 10명이 만들어져요.
- 주인만: 새로 뽑기, 리리 사용. 다른 사람들은 남는 캐릭터 하나를 "내 캐릭터"로 골라서 사용해요.
- 주인을 바꾸고 싶으면 Firestore에서 `meta/config` 문서를 지우고 새로 여세요.
- 익명 로그인이라 브라우저마다 다른 사람으로 취급돼요 (브라우저 데이터를 지우면 내 캐릭터 선택이 풀려요).

`firebase-config.js`가 비어 있으면 서버 없이 혼자 보기 모드로 열려요.
